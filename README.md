# Hugging Face Sentiment Analysis — Basic Practice

## 📌 Overview
This repository contains a basic hands-on practice exercise using
Hugging Face Transformers to explore pretrained NLP models.

The objective was to understand how to load a pretrained model
and use it to classify text as positive or negative.

## 🎯 Learning Objectives
- Understand the basics of Hugging Face Transformers.
- Explore pretrained language models.
- Learn how to use the `pipeline()` function.
- Perform sentiment analysis on sample movie reviews.
- Understand the difference between model training and inference.

## 🛠️ Technologies Used
- Python
- Hugging Face Transformers
- DistilBERT
- Google Colab

## ⚙️ Implementation
1. Installed the Hugging Face Transformers library.
2. Loaded a pretrained DistilBERT model fine-tuned for sentiment analysis.
3. Provided sample movie reviews as input.
4. Generated sentiment predictions and examined their scores.

## 💻 Example

**Input:**
"This movie was amazing. I absolutely loved it!"

**Expected Output:**
- Sentiment: POSITIVE
- Score: Model confidence-like score

The actual score may vary.

## 📚 Key Learnings
Through this practice exercise, I learned how to:
- Load and use a pretrained NLP model.
- Perform inference on new text.
- Interpret sentiment classification results.
- Explore Hugging Face's tools for working with pretrained models.

## ⚠️ Scope and Limitations
This is a basic learning exercise intended to explore Hugging Face
Transformers and pretrained sentiment analysis models.

The model was used directly without training or fine-tuning.
No systematic model evaluation or performance comparison was performed.

## 🚀 Future Learning
- Explore additional pretrained models.
- Learn about model fine-tuning.
- Compare pretrained models with traditional machine learning
  approaches for sentiment analysis.
